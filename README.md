# NexoStock Pro

## Descripcion del proyecto

NexoStock Pro es un sistema web para catalogo, ventas, inventario, pedidos, clientes y reportes.

El proyecto esta pensado como una aplicacion para administrar productos, controlar existencias, recibir pedidos y revisar informacion basica de clientes y ventas.

## Tecnologias usadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- localStorage
- Git

## Modulos actuales

- Landing page
- Catalogo publico
- Detalle de producto
- Carrito
- Checkout con WhatsApp
- Login temporal
- Dashboard admin
- Productos
- Inventario
- Pedidos
- Clientes
- Reportes

## Funciones actuales

- Crear productos temporalmente
- Editar productos creados
- Eliminar productos creados
- Agregar productos al carrito
- Finalizar pedido por WhatsApp
- Controlar stock con entradas, salidas y ajustes
- Cambiar estado de pedidos
- Ver detalle de pedidos
- Ver detalle e historial de clientes
